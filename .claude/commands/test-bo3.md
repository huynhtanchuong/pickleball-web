---

Chạy hai test file có sẵn:

1. `node referee-game-state.test.js`
2. `node referee-sync-engine.test.js`

Báo cáo dưới dạng 3 dòng:
- Tổng số test, số pass / fail
- Nếu fail: tên test + dòng + nguyên nhân ngắn
- Đề xuất bước tiếp theo (KHÔNG tự fix nếu chưa được hỏi)
